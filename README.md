# racegame

夜の港を舞台にした、3D のドリフトゲームです。車は 1 台です。最終的な目標は、ドリフトを最大限気持ちよくすることです。

鈴鹿サーキットも走れます。コースの線形は OpenStreetMap（relation 284570、Suzuka International Racing Course）、高さは国土地理院の標高タイルです。

- 地図データ: © OpenStreetMap contributors
- 標高: 出典 国土地理院

画像は `assets/graphics/`、音声は `assets/sound/` に置きます。鈴鹿のコースデータは `assets/track/suzuka.txt` です。

## 開き方

Cursor または VS Code でこのフォルダを開き、**Reopen in Container** を選びます。初回はイメージのビルドに数分かかります。

## 操作

**W / S / A / D で運転し、Space を押している間ドリフト**します。
Space を押した瞬間に、ステアを切っている向きへ車の後ろを振り出し、押している間は補助が角度を保ちます。
ドリフト中の A / D は角度の調整になり、曲がる向きへ切ると深く、逆へ切ると浅くなります。逆へ切り続けると切り返します。

| 操作 | キーボード / マウス | ゲームパッド |
|---|---|---|
| アクセル | W / ↑ | RT（R2） |
| ブレーキ・後退 | S / ↓ | LT（L2） |
| ステア | A / D / ← / → | 左スティック |
| ドリフト（押している間） | Space / 左クリック（タッチ） | A（×） |
| スタート（タイトル画面） | Space / 左クリック | A（×） |
| タイトルへ戻る | ESC | |
| リスタート | R | Back（View / Share） |
| カメラ | C | Y（△） |
| ポーズ | P | Start（Menu / Options） |
| 全画面 | F | |
| 操作表示 | H | |
| ステージ | 1 / 2 / 3 | |

起動するとタイトル画面になり、後ろでデモの走りが流れます。

## ステージ

| キー | ステージ | 内容 |
|---|---|---|
| 1 | PORT | 夜の港を一周するコース（約 850m）。海沿いの直線 → クレーン広場の幅 40m のヘアピン → コンテナの間の S 字（3 回切り返し）→ 倉庫の角 → 長い一定半径のカーブ |
| 2 | SKIDPAD | 港の中の円の練習場（半径 34m、幅 28m）。角度を保ったまま回り続ける練習に |
| 3 | SUZUKA | 昼の鈴鹿サーキット |

起動時のステージは `--stage port|skidpad|suzuka` で選べます（既定は PORT）。港の 2 つのコースは `src/adapters/course/` でコードから組み立てています。

画面は追従、近め、遠めの 3 つです。ギアはオートマです。

## ドリフト

車の動きは `src/domain/Car.cpp`、WASD の運転は `src/application/ManualDriver.cpp`、
タイトル画面のデモの自動運転は `src/application/OneButtonDriver.cpp` にあります。

- `Car::stepTire`：前後 2 輪の自転車モデルです。タイヤの滑り角から横向きの力を求めます（Pacejka の簡易式）。
- `Car::stepGrip`：横滑りしない動きです。低速でタイヤの力の計算が不安定になるときに使います。
- アーケード向けの補助：ドリフト中は、指定した角度へ車体の回転を寄せます。
- `ManualDriver`：Space を押した瞬間にステアの向きへサイドブレーキで車の後ろを振り出し、押している間は角度を保ちます。
  ドリフト中の A / D で角度を 17°〜45° の間で変え、逆へ切り続けると切り返します（切り返すと得点の倍率が上がる）。
- `OneButtonDriver`：少し先の中心線へ向けてステアを切り、この先のカーブのきつさから速度を決めます。
  ボタンを押すと、曲がる向きへサイドブレーキで車の後ろを振り出し、後輪のグリップを下げて滑りを保ちます。
  ドリフトの角度はカーブのきつさで決まり、S 字では自動で切り返します（切り返すと得点の倍率が上がる）。

調整用の数値は、それぞれのファイルの先頭に定数としてまとめてあります。

## ドリフトに反応する港

| 仕掛け | 中身 |
|---|---|
| 街灯を灯す | 港の街灯は消えかけています。ドリフトしながら横を通ると、そのときの倍率の色で灯ります（X1 緑、X2 青、X3 マゼンタ、X4 金、X5 白）。高い倍率で通り直すと色が上がります。1 本ごとに 300 点、1 周で全部灯すと「PORT LIT UP」で 20000 点。周回が変わると消えて、また最初から |
| パイロンとドラム缶 | コーナーの内側（クリッピングポイント）にパイロン、出口の外側にドラム缶が置いてあります。当てると飛んで転がり、1 つ 500 点。車の動きには影響しません |

街灯の数と色の並びは、右上の SCORE の下に出ます。ルールは `src/domain/StreetLamps.cpp` と `src/domain/Props.cpp` にあります。

## 演出

| 演出 | 中身 |
|---|---|
| ブルーム | ネオン・街灯・テールランプなど明るい所がにじむ |
| 画面のぶれ・色ずれ | 速いほど画面の端が流れ、深く滑るほど色がずれて鮮やかになる |
| フラッシュと揺れ | 倍率アップ（マゼンタ）・得点の確定（白）・クラッシュ（赤）で画面が光り、カメラが揺れる |
| タイヤスモーク・タイヤ痕 | 滑っている後輪から煙が出て、路面に跡が残る |
| 光の尾 | ドリフト中、テールランプが赤い光の軌跡を残す |
| 火花 | 壁を擦るとオレンジの火花。倍率 X2 以上で後輪から倍率の色の火花（X2 青、X3 マゼンタ、X4 金、X5 白） |
| 街灯の光 | 街灯・照明塔・ネオン・車のライトの光が路面と煙に落ちる |
| 灯る瞬間 | 街灯が灯ると強く光って倍率の色の粒を降らせ、ゆっくり落ち着く。全部灯すと金色に光る |
| 弾いた瞬間 | パイロン・ドラム缶を弾くと粒が散り、カメラが少し揺れる |

## 音

効果音は `tools/generate_sounds.py`（Python と numpy）で合成し、`assets/sound/` に WAV で置いています。作り直すときは次を実行します。

```bash
python3 tools/generate_sounds.py
```

| 音 | 鳴り方 |
|---|---|
| エンジン | 速度から自動でギアを決め、回転数に合わせて高さを変える。ドリフト中は空転して回転が上がる |
| スキール音 | 滑り角が深いほど大きく、高くなる |
| ドリフト開始 | 連続が始まったとき |
| 倍率アップ | 切り返して倍率が上がるたび。倍率が高いほど音が高い |
| 得点確定 | 連続が終わって点が確定したとき |
| クラッシュ | 壁に当たったとき |
| 街灯 | 灯ったとき。ジジッと電気が通ってから澄んだ音が上へ抜ける。倍率が高いほど高い |
| パイロン・ドラム缶 | 弾いたとき。パイロンは軽いコンッ、ドラム缶は金属のゴワン |
| PORT LIT UP | 1 周で街灯を全部灯したときのファンファーレ |

ブラウザでは、ページを一度クリックするかキーを押すまで音が出ないことがあります（ブラウザの自動再生の制限）。

## 開発用のオプション

| オプション | 内容 |
|---|---|
| `--self-test` | 画面なしで鈴鹿を 50 秒走らせて、物理が壊れていないか調べる |
| `--capture <file.png> [frame]` | 指定したフレームの画面を PNG に保存して終わる |
| `--drift` | `--capture` と一緒に使う。150 フレーム目からドリフトのボタンを押し続ける |
| `--autopilot` | `--capture` と一緒に使う。ボタンを押さずに自動運転で走る |
| `--title` | `--capture` と一緒に使う。タイトル画面を保存する |

## ブラウザ版

VS Code では、実行とデバッグで「Chrome で racegame をデバッグ」を選んで F5 を押すと、ビルド・サーバーの起動・Chrome の起動まで自動で行います。

ページは `web/shell.html` で、ゲームを画面いっぱいに表示します。キー入力はゲームに届き、F キーか右上のボタンで全画面になります。

```bash
emcmake cmake -B build-web
cmake --build build-web
python3 tools/serve.py 8080  # キャッシュさせないサーバー
```

`http://localhost:8080/build-web/racegame.html`

## GitHub Pages で公開

`main` に push すると、`.github/workflows/pages.yml` がブラウザ版を Release でビルドして GitHub Pages に公開します。
Actions の画面から手動でも実行できます。

初回だけ、リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** にします。
公開先は `https://<ユーザー名>.github.io/<リポジトリ名>/` です。

## Linux 版

```bash
cmake -B build-native
cmake --build build-native
./build-native/racegame
```

画面は `http://localhost:6080`（パスワード `vscode`）です。コンテナ内では音は鳴りません。

ロジックだけの確認:

```bash
./build-native/racegame --self-test
```
